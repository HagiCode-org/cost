# README requirements

## Product focus

- Introduce the AI application cost estimation site at https://cost.hagicode.com, an interactive calculator that answers whether you plus AI now equal two people or more, by turning a salary, a chosen model, a productivity multiplier and daily token usage into annual cost figures.
- Describe what visitors get: input of salary in a chosen currency, model selection with official pricing context, a verdict on effective people equivalent, annual AI cost against total annual employment cost, a token budget ceiling, special titles, a shareable link that keeps language and theme, and a multi-language interface with light and dark themes.
- Address people who want to estimate AI cost and leverage for themselves or their team. The README is written in Chinese; keep it in Chinese.
- Lead with the product value and what the calculator tells the user before any technical detail.

## Required content

- Open with a short product introduction, the website link and the badges the current README carries.
- Explain the calculator in user terms: what to enter, what results are shown, and how to share a result.
- List only features that the site actually shows, consistent with the interface copy in `src/i18n/locales/`.
- Keep the license badge and any license statement consistent with `LICENSE` (MIT).

## Exclusions

- Exclude analytics keys, tokens, secret values, internal hosts, machine-specific paths and private links.
- Do not describe features the site does not show.
- Keep repository maintenance instructions out of the README: repository layout, internal architecture, dependency pins, CI, build, verification and deployment internals, generated versus hand-written files, and i18n maintenance.
