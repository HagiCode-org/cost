**你 + AI，是不是已经等于两个人甚至更多？** 这是一个交互式的 AI 应用成本估算计算器：输入年薪、常用模型、你主观估计的效率倍数和每天的 Token 用量，它会把这些折算成一整年的 AI 成本，并告诉你「你 + AI」相当于几个人。

适合想为自己或团队估算 AI 成本与杠杆效应的人。

## 你会得到什么

- **等效人力结论**：给出「你 + AI」的等效人力，也就是你借助 AI 之后相当于多少个人在工作。
- **年度成本对比**：把年度 AI 成本与企业年度全用工成本并排展示，并给出占比。
- **Token 预算上限**：算出在选定模型和计价口径下，这份预算最多能买下多少 Token。
- **模型与官方定价**：可选择模型，并查看输入、输出等官方定价口径与来源链接。
- **特殊称号**：根据你的输入与测算结果，解锁对应的特殊称号。
- **可分享的链接**：一键复制当前页面链接，链接会带上语言与主题设置。
- **多语言与明暗主题**：界面提供 10 种语言（en-US、zh-CN、zh-Hant、ja-JP、ko-KR、de-DE、fr-FR、es-ES、pt-BR、ru-RU），并支持浅色与深色主题。

## 如何使用

1. 打开 [cost.hagicode.com](https://cost.hagicode.com)。
2. 选择薪资币种，填写年薪，并选择所在城市类型与岗位。
3. 选择你最常用的模型，填写使用它之后的效率倍数，以及每天大约消耗的 Token（单位为 M）。
4. 点击「开始测算」，查看等效人力、年度 AI 成本与企业年度全用工成本的对比、Token 预算上限和特殊称号。
5. 需要分享时，点击页头的分享按钮复制链接；打开链接的人会看到相同的语言与主题。
